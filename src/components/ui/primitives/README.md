# UI primitives

Adapted from the official [shadcn/ui base-nova registry](https://ui.shadcn.com/docs), downloaded 24 November 2026. See LICENSE.md. Runtime behavior uses @base-ui/react; Lucide supplies icons.

RoomieOS adaptations: explicit palette aliases, 44px touch controls, 1024px mobile breakpoint, 248px/64px sidebar, temporary expansion without cookies. Feature-facing adapters retain controlled drafts and save failure behavior. Review upstream changes against these adaptations; do not regenerate over them blindly.
